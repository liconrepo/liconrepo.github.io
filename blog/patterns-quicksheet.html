About the stars

2. Principles

The rules of thumb that the patterns below put into practice.

Design principles10 items, 8 popular
PatternWhat it isPopularLearn more
Single responsibility (S)A class has one reason to change.★SOLID
Open/closed (O)Add behaviour by adding code, not by editing working code.★SOLID

How to use this sheet

  • Starting a project: pick an architecture (section 1), then apply the principles (section 2).
  • Designing a class or module: scan the design patterns (section 3) for the family that matches your problem: creating, wrapping, coordinating or threading.
  • Solving a problem: read the clue in the DSA description (section 4) and try the matching pattern first.
  • Learning: start with the starred items in each family.
